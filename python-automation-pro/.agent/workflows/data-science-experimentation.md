# Workflow: Ciclo Experimental de Ciência de Dados e Pipelines Inteligentes

## Fase 1: Análise Exploratória de Dados (EDA)
1. Varra as estruturas de dados ou bancos de dados locais (`phd-dba-expert.md`) para entender os esquemas e tipos de dados disponíveis.
2. Formule hipóteses e monte o design do experimento no formato `.agent/specs/data-science-experiment-spec.md`.

## Fase 2: Execução e Validação do Modelo
1. Acione o subagente especializado em pipelines de dados (`python-ds-architect.md`) para processar os volumes de dados conforme o planejado.
2. Execute os testes estatísticos e valide os resultados contra os critérios mínimos antes de empacotar o artefato para o Tech Lead homologar.
