# Data Science and Statistical Tools

Esta skill representa um conjunto conceitual de ferramentas voltadas à análise estatística de dados, cobrindo inspeção de distribuições, validação de integridade e apoio à construção de matrizes de confusão para avaliação de modelos.

## Operações

* **analyze_data_distribution** — Inspeciona amostras de arquivos ou tabelas de dados para identificar correlações, desvios padrão e anomalias estatísticas. Entrada esperada: `data_source_path` (caminho do arquivo ou identificador da tabela de dados).
