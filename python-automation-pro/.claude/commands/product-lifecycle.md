# Workflow: Ciclo de Vida de Produto e Validação de Épico

## Fase 1: Discovery e Mapeamento
1. Receba o input do usuário e cruze com as notas existentes na `memoria obsidian`.
2. Formule a estratégia utilizando o template `.claude/specs/product-discovery-spec.md`.

## Fase 2: Passagem de Bastão (Hand-off)
1. Encaminhe a Spec de Produto para o **Analista de Requisitos** (`requirements-analyst.md`) e para o **Scrum Master** para que o épico seja quebrado em tarefas funcionais e sprints técnicas.
